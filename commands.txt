LET'S THINK CHESS — RUNBOOK
===========================

COLAB / KAGGLE GPU (paste one cell; no cd needed)
--------------------------------------------------

!test -d transformer-chess/.git || git clone https://github.com/nareshkarthigeyan/transformer-chess.git; bash transformer-chess/scripts/cloud_train.sh

The launcher installs Stockfish and Python packages. If data/*.pgn is absent,
it downloads a bounded public Lichess PGN corpus. It writes best.pt, last.pt,
epoch snapshots, training.log.txt, JSONL metrics, and a JSON summary.


PERSIST COLAB OUTPUTS ON DRIVE
------------------------------

!bash scripts/cloud_train.sh \
  --data-dir /content/drive/MyDrive/chess_pgns \
  --checkpoint-dir /content/drive/MyDrive/let_think_chess/checkpoints \
  --log-path /content/drive/MyDrive/let_think_chess/logs/training.log.txt \
  --metrics-path /content/drive/MyDrive/let_think_chess/logs/training_metrics.jsonl


RESUME AFTER A DISCONNECT
-------------------------

python run_train.py --preset presentation --resume auto


LOCAL INSTALL + TRAIN
---------------------

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

# macOS
brew install stockfish

# Ubuntu/Debian
sudo apt-get update && sudo apt-get install -y stockfish

python run_train.py --preset presentation


EVALUATE AND PLAY IN THE WEB UI
-------------------------------

python evaluate_elo.py --checkpoint checkpoints/best.pt --media
CHECKPOINT_PATH=checkpoints/best.pt python app.py

Open http://127.0.0.1:5001

-----------------

python run_train.py --preset smoke --max-positions 1000

IMPORTANT MEASUREMENT NOTE
--------------------------

Evaluation exports a baseline-relative proxy, not official Elo. Use the
training logs, match record, fixed Stockfish setting, and live centipawn-loss
reviews as the presentation evidence. See README.md and CHANGES.md.
