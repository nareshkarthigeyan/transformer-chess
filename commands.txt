TRANSFORMER CHESS — FRESH INSTALL COMMANDS
===========================================

These commands install the demo, download the checkpoint from Hugging Face,
and start the local UI. The checkpoint is intentionally not stored in Git.


macOS
-----

# Install system tools (Homebrew: https://brew.sh)
brew install python git stockfish

git clone https://github.com/nareshkarthigeyan/transformer-chess.git
cd transformer-chess

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

python -c "from huggingface_hub import hf_hub_download; hf_hub_download(repo_id='nareshkarthigeyan/intuition1', filename='checkpoint.pt', local_dir='.')"

# Open http://127.0.0.1:5001 after this starts.
python app.py

Windows (PowerShell)
--------------------

# Install Python and Git. Restart PowerShell after these commands.
winget install --id Python.Python.3.12 -e
winget install --id Git.Git -e

# Stockfish is optional for Transformer-only mode. With Chocolatey:
choco install stockfish -y
# If Stockfish is installed somewhere else, point the app at the binary:
$env:STOCKFISH_PATH = "C:\\Program Files\\Stockfish\\stockfish.exe"

git clone https://github.com/nareshkarthigeyan/transformer-chess.git
cd transformer-chess

py -3 -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

python -c "from huggingface_hub import hf_hub_download; hf_hub_download(repo_id='nareshkarthigeyan/intuition1', filename='checkpoint.pt', local_dir='.')"

python app.py
# Open http://127.0.0.1:5001


If PowerShell blocks activation

Provider controls
-----------------

The UI offers Transformer only, Stockfish only, and Hybrid. Hybrid keeps the
assist rate between 50% and 70% and shows the provider used on each engine move.
To force a provider path from a shell, set STOCKFISH_PATH before starting the
app. The app still works in Transformer-only mode without a Stockfish binary.
